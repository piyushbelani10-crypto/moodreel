# Moodreel

Moodreel is a mood-based movie recommendation web app for cinephiles.

Users choose a mood such as happy, sad, romantic, thrilled, thoughtful, weird, or inspired. The app recommends films with short summaries, tags, ratings, and platform search links.

## Features

- Mood-based recommendations
- Bollywood and international movie picks
- Search by title, director, tag, or vibe
- Pace and era filters
- Platform search links
- Progressive Web App support
- Offline caching after the first load

## How to run locally

Open `index.html` directly, or run the local launcher:

```powershell
.\Start Moodreel.bat
```

Then open:

```text
http://localhost:4173
```

## How to publish on GitHub Pages

1. Create a new GitHub repository named `moodreel`.
2. Upload all files from this folder.
3. Go to repository **Settings**.
4. Open **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/root`.
7. Save.

Your site will be published at:

```text
https://your-github-username.github.io/moodreel/
```
